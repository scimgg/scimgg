# Sol Heredit / Colosseum — unverified behavior register

This register lists the implemented game-behavior choices **not established by captures**, the
omissions and exceptions that qualify them, and for each the recording that would settle it.
Practice controls, generic engine policy and capture-verified rules are excluded; partially verified
rules appear only for their unverified boundary or extrapolation. The
[facts spec](./sol-heredit-facts-spec.md) holds the verified evidence and the
[capture inventory](./sol-heredit-facts-spec.md#captures) defines the aliases K/M/N/L/A/B/C.
`T` = warning, `H` = triple hit, `F` = beam fire, `E` = sand emission, `D` = Sol death;
`U[a,b]` is an inclusive integer roll.

Labels: **MODEL** = fit to captures, not a recovered law; **WIKI-ONLY** = published rule or
extrapolation without a capture test; **POLICY** = simulator policy where the captures do not
distinguish the alternatives; **UNVERIFIED** = guess, unresolved boundary or known unmodeled
exception. A code comment calling an unsupported assumption “MODEL” does not make it a capture fit.

Source shorthand (all paths rooted at `src/`): **N/** = `npcs/colosseum/`, **S/** =
`encounters/solHeredit/`, **M/** = `encounters/colosseum/modifiers/`, **R/** = `render/`.
After a filename, a named constant or function is the locator.
